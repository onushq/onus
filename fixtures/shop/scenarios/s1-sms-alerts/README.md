"Text customers when their order ships." A large (~1,400 line, 23 file) feature in notifications: a new `@acme/sms` dependency, an `OrderShipped` subscription, and an SMS pipeline (E.164 normalization, templates, quiet hours, retry with backoff, rate limiting, delivery logging, eligibility via a new optional `phoneVerified` preference), plus tests. The public API of notifications is unchanged.
